Политика конфиденциальности Uniq Bot

Дата обновления: 30 октября 2026 года.

Какие данные обрабатываются

  • Telegram ID пользователя: для проверки доступа по белому списку.
  • Видеофайлы из папок Google Диска, ссылки на которые отправляет пользователь, и их названия.
  • Папки и файлы, которые бот сам создаёт на Google Диске.

Доступ к Google Диску

Бот использует право drive.file: для записи ему доступны только созданные им файлы и папки. Исходные ролики он читает только по ссылке с открытым доступом.

Как используются данные

Данные используются только для обработки видео и выдачи результата. Они не продаются, не используются для рекламы и не передаются третьим лицам, кроме Telegram и Google, через которые работает бот.

Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Хранение

Временные копии на сервере удаляются после загрузки результата. Папки с результатами хранятся на Google Диске, пока их не удалит владелец. Папка с результатами доступна всем, у кого есть ссылка на неё.

Как отозвать доступ

Доступ можно отозвать в любой момент в разделе «Сторонние приложения и сервисы» аккаунта Google.
